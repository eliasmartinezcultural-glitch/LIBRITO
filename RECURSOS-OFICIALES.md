## Protocolo para incorporar cualquiera de estos archivos

1. Descargar desde el dominio oficial y conservar la URL exacta, fecha y organismo.
2. Verificar que el archivo abre, que está completo y que coincide con el título y la edición.
3. Registrar número de páginas, tamaño, formato y SHA-256.
4. Determinar las condiciones jurídicas para reproducir y ofrecer una descarga propia.
5. Si no hay permiso o base jurídica clara, mantenerlo como fuente de consulta externa, sin copiarlo a la carpeta de documentos.
6. Solo después de cumplir los pasos anteriores, actualizar catalogo.json y probar la descarga directa.

**Nota:** que un organismo ofrezca un PDF para consulta o descarga no equivale automáticamente a una autorización general para volver a publicarlo en otro sitio.
